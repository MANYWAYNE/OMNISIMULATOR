# ║   OMNISIMULATOR - Python Requirements                                          ║
# ╚══════════════════════════════════════════════════════════╝
#
# CORE — required for the package to load and the large majority of
# nodes to work. Install with:
#   pip install -r requirements.txt

torch>=2.0.0            # already ships with ComfyUI
numpy>=1.24.0            # already ships with ComfyUI
Pillow>=9.0.0            # already ships with ComfyUI
scipy>=1.10.0             # camera pipeline, FFT match, GLCM/LBP normalize
scikit-image>=0.20.0      # GLCM/LBP texture analysis
piexif>=1.1.3             # EXIF fallback handling
requests>=2.28.0          # Batch Image Generator (API calls)

# ── OPTIONAL — every node below has a built-in, dependency-free fallback.
# Installing these unlocks higher-quality results but nothing crashes
# without them; OMNISIMULATOR prints a one-line notice explaining what's in use.

# scikit-learn: Blend Colors node uses real k-means clustering.
#   Without it: falls back to PIL palette quantization (slightly lower quality).
scikit-learn>=1.0.0

# opencv-python: Camera Simulator gets a real Bayer demosaic + affine-warp
# chromatic aberration; CLAHE color correction uses proper LAB CLAHE.
#   Without it: bilinear demosaic + numpy-based CA + histogram-eq fallback.
opencv-python>=4.7.0

# lpips: Texture Engine / UnMarker-style spectral nodes use real AlexNet
# perceptual distance for the highest-fidelity results.
#   Without it: a built-in multi-scale edge+contrast proxy is used instead
#   (modules/detection_bypass/utils/perceptual_loss.py) — no weight
#   downloads, no internet access needed, works identically otherwise.
lpips>=0.1.4

# kornia: only used by the (currently unused) experimental AdaptiveFilter
# helper. Every active node (Realistic Noise, JPEG Degradation, Texture
# Engine) now uses a pure-torch blur/grayscale implementation instead.
kornia>=0.7.0

# ── ExifTool — required at the OS level (not a pip package) for
# "OmniSimulator Save With Metadata" to inject EXIF/GPS/ICC data. Without it, the
# node still saves plain JPEGs, it just skips metadata injection and
# prints a warning.
# Windows : https://exiftool.org  →  add exiftool.exe to PATH
# Linux   : sudo apt install libimage-exiftool-perl
# macOS   : brew install exiftool
